# 安全与隐私边界

- 用户身份只从服务端验证后的 JWT 获取，禁止相信请求体中的用户 ID。
- 教案、文件、知识库和工作流记录按 owner_id 隔离。
- 上传文件限制为 PDF、DOCX、PPTX、XLSX、TXT 和 Markdown，最大 20MB。
- API Key、数据库密码和 JWT 密钥只通过环境变量注入。
- 日志禁止记录 JWT、模型密钥、学生姓名、原始成绩表和完整 Prompt。
- 检索到的文档内容视为不可信数据；其中的指令不得覆盖系统指令。
- 学生数据仅用于统计和建议，确定性计算与大模型解释分离。
- 学情分析按登录用户校验成绩文件归属，调用模型前以“目标学生”代称，不在 Prompt 中携带学生姓名。
- 生产环境应配置对象存储、病毒扫描、数据保留期限、审计日志和删除流程。

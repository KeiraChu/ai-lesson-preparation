# AI 质量评测

项目通过离线数据集与线上观测共同评估 AI 能力。评测数据不得包含真实学生姓名、手机号或其他个人信息。

仓库中的跨学科记录是验证评测管线的合成样例，其中包含证据不足时应拒答的案例。`run_evals.py` 会为每条记录重新执行文档切分、Embedding、混合检索、生成与引用校验，不读取预先写好的答案、引用或延迟。演示 Provider 的结果只能证明管线可以稳定回归；正式效果结论必须配置真实模型并使用扩充后的人工标注集。

## RAG 指标

- Retrieval Hit Rate：期望资料是否出现在召回结果中。
- Recall@K 与 MRR：召回覆盖率及正确资料排序。
- Citation Coverage：回答中的关键结论是否有资料引用。
- Groundedness：回答是否能够由引用原文支持。

## 生成指标

- JSON Schema 解析成功率。
- 教学目标、重点难点、课堂活动和作业的完整率。
- 教材一致性、题目与知识点匹配度及无依据陈述比例。
- 首 Token 延迟、总延迟、输入/输出 Token 和单次调用成本。

## Bad Case 流程

失败样本必须记录输入、检索结果、Prompt 版本、模型、输出、人工标签和修复方式。修改检索策略、Prompt 或模型后运行同一数据集回归，避免只优化单个示例。

# 八年级数学：一次函数

一次函数通常表示为 `y = kx + b`，其中 `k`、`b` 为常数且 `k ≠ 0`。当 `b = 0` 时，它也是正比例函数。

## 图像与性质

一次函数的图像是一条直线。`k` 决定直线的倾斜方向：当 `k > 0` 时，`y` 随 `x` 增大而增大；当 `k < 0` 时，`y` 随 `x` 增大而减小。`b` 是直线与 `y` 轴交点的纵坐标。

## 建模步骤

1. 明确自变量和因变量。
2. 根据题意寻找两个量之间的线性关系。
3. 用待定系数法或已知条件确定 `k`、`b`。
4. 检查自变量取值范围，并结合实际情境解释结果。

## 教学建议

课堂可以从出租车计费、匀速运动等真实问题导入。学生应经历“表格—关系式—图像—情境解释”的转换过程，并能使用函数图像比较不同方案。

## 分层练习

- 基础：判断给出的关系式是否为一次函数。
- 进阶：根据两个点求一次函数解析式。
- 拓展：比较两种计费方案，并说明在哪个区间选择哪种方案更合适。
